- 全屏截图 control+shift+alt+3
* 区域截图 control+shift+alt+4
* 截图/录屏启动器 shift+command+5
* 左右切换空间 control + 左右
* 显示当前应用窗口 control + 下箭头
* 显示/隐藏拓展坞  command +  option + D
* 打开强制退出窗口 Command ⌘ + Option ⌥ + Esc
* 直接强制退出 Command ⌘ + Option ⌥ + Shift ⇧ + Esc
* 最小化当前窗口 Command ⌘ + M
* 启动台，可以通过触发角或者设置默认F5打开
